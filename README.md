# HailLearn

A learning platform built with a React frontend and Node.js backend.

## Project Structure

```
HailLearn/
├── frontend/   # React application
└── backend/    # Node.js API server
```

## Getting Started

### Backend

```bash
cd backend
npm install
npm run dev
```

### Frontend

```bash
cd frontend
npm install
npm run dev
```

## Tech Stack

- **Frontend**: React, TypeScript
- **Backend**: Node.js, Express
